# Legacy Teller Automation

A computer-use automation system: an LLM discovers how to complete a goal against
a legacy bank-style UI, records the successful run as a reusable, typed artifact,
and replays that artifact deterministically without the LLM in the loop.

Status: work in progress (Phase 0 — project scaffold).
